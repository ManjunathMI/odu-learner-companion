# Create and manage a Learning Space

Create a Learning Path when you want to organize learning for yourself or a group.

## Create your path

Sign in, open [My Journey](/journey), and choose the create action. Add a clear title, description, and useful tags. Creating a path makes you its facilitator with management access for that path.

## Build the learning plan

Open path settings and organize resources into phases, days, and lessons. Add useful resource links and save your changes. Review removal warnings carefully: removing a lesson can remove the progress and notes attached to that lesson.

## Manage membership

Use the approvals view to review requests. Path administrators can manage members and delegate moderator responsibilities through the controls provided for that space. A moderator's permissions apply only to the relevant path.

## Make a path discoverable

Private paths stay outside public discovery. Choosing public visibility does not immediately publish a path on Explore: it also requires platform publication approval.

## Understand creator capacity

The default allowance is three paths you create. Joining another person's path does not use that allowance. Review your current capacity in Manage Account; quota requests let you ask for a higher limit.
