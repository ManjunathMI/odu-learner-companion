# Create a Learning Path

A **Learning Path** is a plan made of phases, days, lessons, and resources. When you create one, you become its Space Creator and can manage that path. The path is private by default, so you can work on it before anyone else can find it.

## Before you begin

Think about who the path is for and what they should be able to do by the end. You do not need to write everything before you start. You can save the path and continue in its settings.

## 1. Open the creator

Sign in and go to [My Journey](/journey). Choose **Create a Learning Path**.

## 2. Add the overview

Give your path a clear title. Add a short description and a few useful tags so people know what it covers. The overview field accepts Markdown; you can use it for the audience, prerequisites, learning outcomes, or optional references.

## 3. Build the learning plan

Add a phase for each major part of the learning journey. A phase can have a goal to explain what learners should achieve.

Inside each phase, add days with a label, title, and optional study time. You can add lesson material in Markdown, then add lesson items with a title, a resource URL, and a type such as **Hands-on** or **Exam**. You can move phases, days, and items to change their order.

You can leave optional explanations blank and add them later. Resource links need a title and URL.

## 4. Create and continue in settings

Choose **Create path** to create it. ODU takes you to the path settings page, where you can review the overview, adjust visibility, and continue editing the plan.

If you see a message that your draft was saved but the plan could not be saved, use **Continue editing the saved draft**. That opens the path already created; you do not need to start another one.

## 5. Choose who can find it

New paths are **private**. If you change the visibility to **Public**, it still will not appear on Explore until a Platform Admin approves publication. Private paths are not listed in public discovery. [Contact us through Feedback & help](#feedback) about a review and include the path title.

## 6. Review requests to join

People who want to join your Learning Space send a request. Review requests from the path's approvals area. You can also manage members there. A Moderator can help with the path-specific actions available to that role; they do not become a Platform Admin.

## Creator allowance

The default allowance is three paths you create. Joining another person's path does not count. Check **Manage Account** to see your usage or request a higher limit.

## Common questions

### Can I edit my path after creating it?

Yes. After creation, ODU takes you to its settings page. You can return there later from My Journey or Manage Account.

### Will people see my path as soon as I choose Public?

No. Public visibility and publication approval are separate. A Platform Admin must approve the path before it appears on Explore. [Contact us through Feedback & help](#feedback) if you have a question about the review.

### What should I do if the first save only creates a draft?

Use the **Continue editing the saved draft** link shown in the form. It opens the path that was already created, so you can retry the plan save without making a duplicate path.
